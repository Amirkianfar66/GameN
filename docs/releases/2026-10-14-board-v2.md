# Playable Board V2 staging release

The owner authorized completing Backend and Frontend integration and deploying the playable update to `gamen-mothership-staging` after verification. Integration owns this combined release. This document records preparation; a successful cloud deployment must be recorded separately with its exact source and artifact digests.

## Included behavior

New games use stored logical board positions, a Hospital with one bed per starting player, automatic Hospital placement and the complete following-round rescue deadline. Captain RELEASE and EJECT are independent once-per-match commands on the Captain's own turn in Command Room. Blackout uses the shared end-of-round five-second light and ten-second dark window, frozen positions and private position selection. Alien Clone lasts through the following normal round, blocks eligible attacks repeatedly before Protection, and preserves its original expiry through detention. The exact implementations and native versus constructed evidence are in the Backend handoffs for public Hack, Board/medical, Captain, Blackout and Clone.

The Private Talk capsule sits beside Command Room at half its width. Public participation is cinematic: gameplay locations and targeting remain authoritative. The declaration and result precede the full 60-second conversation. In-person V1 has no voice, recording or chat service.

## Limits that must remain explicit

Claude's private Clone film, medical drone/flatline films and Captain console/ejection/release cinematics are not delivered. Their authoritative gameplay and neutral outcome feedback are separate from film acceptance. S1 has no source-authorized public frozen-hit event in this tuple, so the client must not invent impact flashes from snapshots, command registration or medical anchors; the common lighting window remains complete. S4 uses only authorized player-room outcome events.

Initial subscriptions, cache-only data and reconnects establish a current baseline rather than replaying historical films. Animation clocks cannot decide gameplay or consume the server's decision windows. Reduced motion and stale/uncertain-command recovery remain required.

Browser emulation does not constitute a physical-device or screen-reader test. The approved layout has an explicit too-short fallback when the usable viewport cannot fit all 44-pixel positions. Independent Claude Balance's next-version catalog is separate from the historical balance gates; unexecuted or manual cases are not reported as passed. Human social-deduction balance remains a playtest result.
