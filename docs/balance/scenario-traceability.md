# Scenario traceability

Generated by `npm run traceability --workspace @mothership/balance` from the scenario files, the rulebook, the decision register and the pinned matrix. Do not edit by hand; `npm run check` fails when it is out of date.

A scenario is a fixture: recorded inputs and an expected result. Whether a fixture has been executed, and against what, is in [evidence/](evidence/). Nothing on this page is a result.

## Fixtures per mode

The three modes are separate files and separate evidence. They are never added together to claim coverage of "the game".

| `tests/scenarios/v1/unsupported.scenarios.json` | Configurations the rules do not allow | 8 | 0 | 0 | 8 |

Ready means the expected result is derived from decided rules and can be executed. Blocked means the case waits for an owner decision and asserts nothing. Manual means the evidence must come from the service, the user interface or people, not from an engine run.
